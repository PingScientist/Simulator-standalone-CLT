# 三分鐘展示腳本

可直接點右上角「三分鐘導覽」，或依下列節奏操作。

## 0:00–0:35：一個偏態的微觀世界

選自由分布／強偏態，n=1，標準化座標。按單步，指出母分布上抽出的值，如何成為直方圖的一次結果。說明每次含 n 個樣本、總共重複 M 次。

## 0:35–1:10：逐步形成高斯

改 n=16，再改 64；使用快速統計。對比青色實測、紫色有限 n 理論、金色常態近似。增加 n 改變理論分布，增加 M 主要降低實測雜訊。

## 1:10–1:40：共同極限

展開普適性畫廊，比較均勻、偏態、雙峰與雙態的 Z 分布。切換總和與平均，說明 SD(S)=σ√n，而 SD(X̄)=σ/√n。標準化才能公平比較形狀。

## 1:40–2:20：真實物理連結

切順磁體，顯示磁矩方向與平均磁化波動。使用場／溫度控制，指出 E=−hs、E[s]=tanh(h/kBT)。此模型無自旋耦合，每次是獨立平衡組態。可按掃描 n 展示平均波動的平方根尺度律。

## 2:20–2:50：條件比口號重要

切 Cauchy，指出平均與變異數不存在，標準化按鈕被停用。增加 n 不會讓平均集中成高斯。若時間允許，切相關樣本令 g=n，說明複製同一資料不會增加獨立資訊。

## 2:50–3:00：交付與驗證

展示「引擎與驗證」的數值自檢，以及 POE 筆記。說明只需一個 HTML、無網路與安裝，並可匯出實驗數據。

## 預備回答

- **為什麼不是每次都貼住理論線？** 有限 M 的抽樣雜訊；有限 n 的理論也通常不等於高斯。
- **n=30 是否足夠？** 沒有普遍門檻，偏態、稀有事件與尾端都影響近似品質。
- **粒子動畫是不是實際分子動力學？** 不是；順磁體是平衡抽樣，隨機漫步是粗粒化離散模型。
- **能量怎麼不守恆？** 順磁體處於熱浴中，系統本身可交換能量；此題檢驗的是概率與統計矩。
