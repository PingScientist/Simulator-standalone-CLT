# 物理模型與適用條件

## 獨立同分布 CLT

對具有有限平均 μ 與 0 < σ² < ∞ 的 i.i.d. 變數，Sₙ = ΣXᵢ，X̄ₙ = Sₙ/n，Zₙ = (Sₙ−nμ)/(σ√n) 在分布上收斂至 N(0,1)。總和變異數為 nσ²，平均變異數為 σ²/n。

只要求二階矩時，特徵函數展開為 φ_W(t)=1−t²/2+o(t²)。三階餘項界與 Berry–Esseen 速率需要額外矩條件。有限 n 的二項分布仍是離散的，不能因曲線相近而寫成精確高斯。

## 自由分布

有限分布使用 K 個等距中點 xᵢ = −1 + 2(i+1/2)/K（K=64、128、256、512），權重正規化成 PMF。μ、σ 都以此實際抽樣模型計算。

- 強偏態：權重 proportional to exp[−4(x+1)]，支撐有限於 [−1,1] 的離散近似。
- 均勻、三角、雙峰：同一中點格點上的對應權重。
- 雙態：X=±1，P(+1)=p。
- 高斯：未截斷的 N(0,1)。
- 指數：未截斷的 Exp(1)，總和為 Gamma(n,1)。
- 確定值：X=1/2，σ=0，Z 不定義。
- 手繪：128 個可編輯非負高度插值到 K 個位置，再正規化；不使用負機率。

## 順磁體

使用 s=±1，單粒子能量 E=−hs，h=μₘB。以 E₀ 為能量單位，介面外場 b=h/E₀，溫度 θ=kBT/E₀，a=b/θ。

Z₁=2cosh(a)，P(+1)=(1+tanh a)/2，E[s]=tanh a，Var(s)=1−tanh²a。

總磁矩是 μₘΣsᵢ；介面顯示無因次磁矩和或平均。沒有鄰居耦合，格點不造成空間相關。每次重新抽樣是新的平衡系綜組態，而不是已標定的時間演化。系統接觸熱浴，其能量可以波動。

固定非零場取 T→0 得到完全極化。T→∞ 以 θ=10¹⁵ 顯示在機器精度下近似的等機率極限。零場與零溫的聯合極限不定義單一答案，拒絕未指定路徑的狀態。

## 隨機漫步

Δx=±ℓ，右向機率 p。n 步後 E[xₙ]=n(2p−1)ℓ，Var(xₙ)=4np(1−p)ℓ²。顯示採 ℓ=1。p=1/2 時 E[xₙ²]=nℓ²，若 t=nΔt，D=ℓ²/(2Δt)。

所有步進參與終點計算。路徑最多保存約 180 個折線點，僅為繪圖抽稀；沒有反射、週期回捲或吸收邊界。這是 Brownian diffusion 的離散粗粒化模型。

## 群組相關

每組 g 個位置共用 Yⱼ，各組獨立，n 必須可被 g 整除。Sₙ=gΣⱼYⱼ，Var(Sₙ)=ngσ²，Var(X̄ₙ)=gσ²/n，n_eff=n/g。

本模式 Z 使用真實 √(ng)σ 標準化。紫線為群組模型，金線刻意顯示「把所有位置當獨立」的預測；Dₙ 仍比較以真實變異數配對的高斯。固定 g 且 n→∞ 可再次符合 CLT；g=n 時平均保留單一 Y 的分布。

## Cauchy

X=tan[π(U−1/2)]，U∈(0,1)。理想模型 f(x)=1/[π(1+x²)]，特徵函數 e^{−|t|}；Sₙ/n 仍為同一標準 Cauchy。普通意義的均值、變異數不存在。

有限精度 PRNG 能產生的數值有機器上限；實作不另施加人為抽樣截斷。畫面範圍外的值保留在 sums、CSV 和 JSON，顯示尾端數量。中位數理論值 0，IQR 理論值 2；總和座標的 IQR 為 2n。
