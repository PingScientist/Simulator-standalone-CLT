# 數值方法與可重現性

## 隨機抽樣

Mulberry32，32-bit state；輸出 `(uint32 + 0.5)/2^32`，不包含 0 與 1。有限 PMF 採 CDF 二分搜尋。高斯採 Box–Muller（不保留額外備用樣本），指數／Cauchy 採逆變換。

主實驗每次固定依序抽取 n/g 個獨立樣本。是否保存動畫、播放速度、圖表與配色都不消耗主亂數流。畫廊與掃描使用各自固定種子，不干擾主實驗。

## 理論分布

有限等距 PMF 的 n 次線性卷積使用 radix-2 FFT，變換長度選擇不小於 n(K−1)+1 的 2 次方，避免循環卷積混疊。頻域整數冪使用二進位乘方。反變換後若有小於 −10⁻⁹ 的概率或非有限數值則報錯；小負值截為 0，總質量需在 10⁻⁷ 內接近 1，再消除浮點偏差。

雙態使用二項分布的對數權重正規化，處理 p=0、1 與極端偏置。高斯總和 N(0,n)、指數總和 Gamma(n,1) 與 Cauchy 總和 Cauchy(0,n) 使用解析模型；Gamma CDF 使用下不完全 Gamma 級數或上尾連分式。

理論曲線不從實測均值／標準差擬合。母分布矩提供獨立的預測，可揭露抽樣錯誤。

## 統計與繪圖

- 線上中心矩累積；實測 SD 使用樣本變異數 M2/(M−1)。
- 直方圖高度為 `count/(M*binWidth)`；有限 n 曲線為同區間理論機率除以區間寬。
- 高斯參考是 PDF，可與密度直方圖比較；不在可見視窗內重新正規化。
- 橫軸變換包含相應尺度變換，總機率保持一致。
- 離散 CDF 距離檢查每個跳躍左右側。常態 CDF 使用標準多項式近似，精度約 10⁻⁷ 級。
- Gamma 的 Dₙ 在 Z∈[−8,8]、間距 .05 上估計，明確標示網格估計。
- Q–Q 顯示 1%–99% 分位數；ECDF 最多約 800 個繪圖點，排序仍使用全部樣本。

## 集中狀態

`simState` 保存 config、UI、model、theory、rng、sums、統計、抽樣快照、POE、Chart 實例、Worker、快取與時間資訊。純數值 API `CLTMath` 不依賴 DOM。

改變物理／分布參數會清除主實驗數據，固定 A 組不受影響。改變速度、主題、直方圖區間與觀察座標不重新抽樣。

## 效能與界限

- n≤1024；M≤100,000；FFT≤2¹⁹。
- 主執行緒抽樣每次約 7 ms 的軟時間預算；單次 trial 本身仍需完成。
- requestAnimationFrame 啟動動畫；微觀 Canvas 約 30 Hz，Chart 約 180 ms 更新，分析約 650 ms；暫停或達到目標時立即完整刷新，確保最終數據同步。
- 主 FFT 在 Blob Worker 執行；Worker 不可用時採有界主執行緒備援並提示可能等待。
- 快取最多 12 項或 16 MiB 的 PMF；只接受目前 revision 的結果。
- 畫面最多呈現 128 個微觀樣本、32 條路徑、最近 160 次波動。完整統計仍保留最多 100,000 個實驗總和。
- 隱藏頁面停止計算；返回時不補算背景時間。

## 離線封裝

所有樣式、程式與字型內嵌。沒有 fetch、ES module import、CDN script 或必需相鄰檔案。Worker 從當前 HTML 內的純數值 script 建立 Blob。外部 `<a>` 僅為使用者主動開啟的教材連結。

匯出透過 Blob 下載。剪貼簿受瀏覽器限制時提供可選取文字。JSON 限制 16 MiB、版本、數值範圍、陣列長度與實驗數量，驗證後才載入。
